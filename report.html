PROJECT REVIEW

Photo Audit Workspace

摄影平台供稿审核后台 — "AI 机审 + 人工复核" MVP 项目面试报告

技术栈：HTML5 · Tailwind CSS · Vanilla JS 类型：前端 MVP 部署：零依赖 · 静态站点
01 · Overview

项目概述

本项目是为现代 UGC 摄影平台设计的供稿审核后台最小可行性产品（MVP）。针对平台每天海量图片审核中的效率低下、风险漏判、标准不一三大痛点，引入 "AI 机审拦截 90% 低质稿件 + 人工专注 10% 争议内容" 的双层审核工作流。

02 · Pain Points

业务痛点与解决方案

● 痛点 1：效率低下

海量图片的初筛耗费大量人工，出审时效以分钟计，严重影响创作者体验与平台周转。

● 方案 1：AI 批量初筛

AI 在 1.2s 内完成内容分析，自动拦截 90% 低质稿件，人工只需复核争议内容。

● 痛点 2：风险漏判

人工疲劳导致版权争议、政治敏感内容漏放，平台合规压力大。

● 方案 2：安全兜底策略

高风险内容采取"宁可错杀不可放过"策略，召回率 99.2%，确保风险内容全部进入人工复核队列。

03 · Features

核心功能模块

🤖

AI 智能辅助审核

支持 Gemini 2.0 Flash（视觉审核）与 DeepSeek Chat（元数据盲审）双模型，上传后自动给出评分与建议标签。

🖥️

沉浸式审核工作台

暗黑模式设计，卡片网格布局，hover 操作、滑出动画，为影像工作者优化的专业体验。

🔄

摄影师申诉闭环

打回 Toast 附带 Appeal 按钮 → 申诉浮层 → 提交理由 → 联动审核日志，形成完整闭环。

📊

业务实时看板

侧边栏展示今日已审、平均出审时效、机审召回率等核心指标，数据持久化至 localStorage。

📋

审核日志系统

实时记录每一次 Approve / Reject / 申诉操作，带时间戳，刷新不丢失。

🔑

灵活 AI 接入方案

页面横幅输入 API Key，额度耗尽自动检测并引导模型切换，支持模拟/真实双模式运行。

05 · AI Strategy

AI 审核策略与双模型设计

系统设计了差异化审核策略：Gemini 负责真正的内容理解（安全/质量/版权），DeepSeek 通过文件元数据进行低成本盲审，两者通过统一分发器 callAIForReview() 自动路由。

DeepSeek 元数据盲审规则矩阵

文件格式文件大小AI 判定评分区间
PNG< 50KB疑似截图/盗图30–45
PNG50–200KB边缘可疑，人工复核50–65
RAW / TIFF> 5MB专业级原始文件85–95
JPEG> 2MB优质投稿75–90
JPEG< 200KB严重压缩，画质损失45–65
WEBP / GIF任意疑似第三方转载55–75

💡 设计亮点

额度耗尽自动检测（HTTP 402/429 + 关键词匹配），弹出 Amber 提示引导无缝切换模型；API Key 全程在浏览器内存中，不写死代码；图片自动压缩（最大 1024px + JPEG 0.8 质量）再送入 API，控制调用成本。

06 · Highlights

技术亮点与工程思考

⚡

零后端架构验证

通过 localStorage 实现了完整的数据持久化方案，包括已审卡片防复现、审核日志、今日统计、API Key 管理，MVP 阶段完全自洽。

🎨

暗黑模式 UX 设计

专为影像工作者设计的沉浸式 Dark Mode UI，暗角叠加、悬浮操作、滑出动画，体现对目标用户工作场景的深度理解。

🔀

统一分发器模式

callAIForReview() 根据 provider 自动路由，新增模型只需在分发器中加一条分支，遵循开闭原则，具备良好的可扩展性。

🔒

安全与合规设计

API Key 安全存储于 localStorage，高风险内容"宁可错杀不可放过"策略确保平台合规，审核日志全量追溯。

07 · Summary

项目价值总结

  • 业务价值：将 AI 能力落地到内容审核这一高频场景，直接降低人工成本，提升审核效率与平台合规性。
  • 技术价值：纯前端实现完整 AI 集成方案，涵盖多模型分发、额度管理、图片预处理、数据持久化，是一个麻雀虽小但五脏俱全的全栈式前端项目。
  • 产品思维：从痛点分析 → 指标设计 → 功能实现 → 申诉闭环，展现了完整的产品视角和闭环思维。
  • 工程素养：代码组织清晰（单文件但模块分明），动画与交互细节到位（Toast、滑出、Modal），体现了对前端工程与用户体验的双重关注。
